Wie kannst du mitspielen?

1

Minecraft starten

Öffne Minecraft Java Edition (Version 1.21.11+).

2

Cytooxien.net betreten

Verbinde dich mit dem Server cytooxien.net.

3

Realm-Kompass öffnen

Drücke F3 + G oder nutze den Realm-Kompass.

4

IdeenGames auswählen

Wähle den Realm IdeenGames aus der Liste aus.

Häufig gestellte Fragen

Ist IdeenGames kostenlos?

+

Ja, IdeenGames ist komplett kostenlos. Du brauchst nur eine gültige Minecraft Java Edition.

Brauche ich Mods?

+

Nein, du brauchst keine Mods. IdeenGames läuft mit Vanilla Minecraft.

Welche Version?

+

IdeenGames unterstützt Minecraft Java Edition 1.21.11 und höher.

Wie melde ich Bugs?

+

Du kannst Bugs und Feedback über unseren Discord-Server melden.
